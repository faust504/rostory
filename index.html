Quick Start

To start using the Story Engine, you'll need to define a Chapter and some Scenes.

1. Create a Chapter

local Chapter = require(game.ReplicatedStorage.Story.Chapter)
local Actions = require(game.ReplicatedStorage.Story.Actions)

local MyChapter = Chapter.new({
    id = "chapter1",
    name = "The Beginning",
    startScene = "intro",
    scenes = {
        -- Defined below
    }
})

2. Define a Scene

Chapter.scene("intro", "Intro Sequence", {
    Actions.FadeOut(0),
    Actions.Wait(1),
    Actions.PlaySound("rbxassetid://123456"),
    Actions.FadeIn(2),
    Actions.Dialogue("Welcome to the game!", 3),
    Actions.TeleportPlayer(workspace.TargetPart.Position)
})

3. Play it!

local Director = require(game.ReplicatedStorage.Story.Director)
Director:PlaySequence(MyChapter.scenes[1].actions)

Chapter Module

The Chapter module helps you organize your stories into manageable chunks.

Chapter.new (definition)

Registers and creates a new Chapter object.

Parameter Type Description
definition ChapterDefinition Table containing id, name, startScene, and scenes list
Chapter.scene (id, name, actions)

Helper function to create a scene definition table.

Chapter.getScene (chapterId, sceneId)

Retrieves a specific scene from a registered chapter.

Core Actions

Fundamental building blocks for your story.

Actions.Wait (seconds)

Pauses execution for a set time (skippable).

Actions.Dialogue (text, duration?, color?, font?, textSize?)

Displays text on screen with a typewriter effect.

Parameter Type Description
text string The text to display.
duration number Time to stay on screen after typing.
color Color3 Text color.
font Enum.Font Font style.
Actions.Choice (prompt, choices)

Presents a list of choices to the player. Blocks until selection.

Actions.Parallel (...)

Runs multiple actions at the same time.

Actions.ShowObjective (text)

Shows a mission objective at the top of the screen.

Actions.Log (message)

Prints a message to the console for debugging.

Audio Actions 🎵

Audio actions for the story.

Actions.PlaySound (soundId, volume?, delay?)

Plays a sound effect once.

Parameter Type Description
soundId string Roblox asset ID.
volume number (Optional) Volume, defaults to 1.
delay number (Optional) Delay in seconds before playing.
Actions.PlaySoundAndWait (soundId, volume?)

Plays a sound and waits for it to finish before continuing.

Actions.PlayLoopingSound (soundId, name, volume?)

Starts a looping sound that continues until stopped.

Actions.StopSound (soundId, fadeDuration?)

Stops a specific sound ID, optionally fading it out.

Actions.StopLoopingSound (name, fadeDuration?)

Stops a named looping sound, optionally fading it out smoothly.

Actions.PlayMusic (soundId, fadeTime?)

Plays background music with cross-fading support.

Actions.StopMusic (fadeTime?)

Fades out the current background music.

Visual Actions ✨

Visual effects for the story.

Actions.FadeOut (duration)

Fades the screen to black.

Actions.FadeIn (duration)

Fades the screen from black to transparent.

Actions.FlashScreen (color, duration?)

Flashes the screen a specific color (e.g., red for damage).

Actions.SetBlur (size, duration?)

Applies a blur effect to the Lighting service.

Parameter Type Description
size number Blur size intensity.
duration number (Optional) Tween duration.
Actions.ScreenShake (intensity, duration)

Shakes the camera violently.

Actions.Blink (holdDuration?)

Simulates an eye blink via fades.

Actions.ShowUI / HideUI (guiName)

Toggles visibility of PlayerGui elements.

Camera Actions 📷

Actions.MoveCamera (targetCFrame, duration?)

Smoothly moves the camera to a new location.

Actions.SetCamera (targetCFrame)

Instantly snaps the camera to a location.

Actions.CameraTilt (angle, duration?)

Tilts the camera.

Parameter Type Description
angle number Angle in degrees.
duration number (Optional) Tween duration.
Actions.FollowPart (part, offset?)

Makes the camera continuously follow a part's movement.

Actions.StopFollowing ()

Stops the camera from following a part.

Actions.ResetCamera ()

Returns control of the camera to the player.

Gameplay Actions 🎮

Actions.WaitForProximity (targetPart, distance)

Waits until the player is within distance of the target part.

Actions.WaitForTrigger (triggerPart)

Waits until the player touches a specific part.

Actions.TeleportPlayer (position)

Instantly moves the player character to a CFrame or Vector3.

Actions.LockPlayer / UnlockPlayer ()

Freezes or unfreezes player movement.

Actions.HideCharacter / ShowCharacter ()

Makes the player model invisible or visible.

Actions.WeldToObject (object)

Welds the player to a moving object.

Actions.WaitForToolEquip (toolName)

Waits for the player to equip a specific tool.

Actions.WaitForToolUse (toolName)

Waits for the player to click or activate a tool.

Animation Actions 💃

Actions.PlayAnimation (target, animationId, waitForComplete?)

Plays an animation on a Humanoid or Model.

Actions.PlayCutsceneAnimation (animationId)

Plays an animation on the local player and waits for it to finish.

Tweening Actions 🚗

Actions.TweenModel (model, targetPart, duration, easingStyle?)

Moves a whole model to a target part's position.

Actions.TweenPart (part, targetPart, duration, easingStyle?)

Moves a single part to a target position.

Actions.TweenPartThroughWaypoints (part, waypoints)

Moves a part through a list of waypoints without stopping.

waypoints = { {target=part1, duration=5}, {target=part2, duration=2} }
Actions.StartBackgroundTween (part, waypoints)

Runs the tween in the background so other actions can continue.
